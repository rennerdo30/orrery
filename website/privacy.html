Privacy

This website

This site has no cookies, no analytics, no trackers and no third-party fonts or scripts. It is hosted on GitHub Pages; GitHub logs the IP addresses of visitors for security and operation. To show the newest version, the download section asks GitHub's public API (api.github.com) for the list of releases, directly from your browser; GitHub receives your IP address for that request. See GitHub's privacy statement for details.

If you open your own model in the live demo, it is read by your browser on your device. It is not uploaded anywhere, and the page blocks any web address a model refers to.

The app

Orrery runs entirely on your PC and makes no network requests at all: no update check, no telemetry. It reads only the model you open and the images and buffers that model needs. The optional register.ps1 writes file association entries under HKCU\Software\Classes and nothing else.
